AI ACCURACY AND MODEL EVOLUTION (V1 vs V2)

1. V1 vs V2 Accuracy Comparison
- V1 Model (DDoS Only): Achieved 99.99% accuracy on the CIC-IDS-2017 Friday dataset.
- V2 Model (DDoS + SSH Brute Force): Achieved 99.98% accuracy on the combined Friday and Tuesday datasets.
- Analysis: Upgrading the model to perform multi-class classification (detecting 3 distinct classes: BENIGN, DDoS, and SSH-Patator) resulted in a negligible accuracy drop of just 0.01%. This proves the model is highly robust and capable of handling multi-vector threats simultaneously without losing precision.

2. Modifications and Methodology
To upgrade the AI from V1 to V2, the following methodology was used:
- Feature Retention: We intentionally did NOT modify or add any new network features. We retained the exact same 8 distinct mathematical features (e.g., Fwd Packet Length Mean, Destination Port). This proves that the selected features are universally effective at identifying volumetric network anomalies without requiring a bloated, compute-heavy feature set.
- Dataset Integration: We concatenated the 'Friday-WorkingHours-Afternoon-DDos' and 'Tuesday-WorkingHours' PCAP datasets from CIC-IDS-2017 to create a multi-threat training environment.
- SMOTE Balancing: Because the combined dataset was heavily skewed towards normal BENIGN traffic, we applied the Synthetic Minority Over-sampling Technique (SMOTE) strictly to the 80% training split. This ensured the model learned the attack signatures equally without bleeding synthetic data into the 20% unseen testing vault.
